# Basic Example — Eddie Package

Esta pasta contém uma cena de exemplo básica do Eddie.

## Como usar

1. No **Package Manager**, localize o pacote **Eddie — Interactive Character**
2. Expanda a seção **Samples**
3. Clique em **Import** ao lado de **Basic Example**
4. A cena será importada em `Assets/Samples/Eddie/1.0.0/BasicExample/`
5. Abra a cena e pressione **Play**

## O que a cena demonstra

- Prefab do Eddie posicionado na cena
- Canvas com `TMP_Text` para legenda conectado ao `PlayAudios`
- `Image` de exemplo conectada ao `PlayAudios`
- Botões para testar `StartLoop()`, `StopLoop()` e `PlayRandomNow()`
